# 一个配置文件，持续沿用

所有 API 设置、密钥、自定义提示词、当前选中的提示词及附带文件选项保存在同一个 `prompt-desk.private.json`。问题、回答和待编辑文件不作为配置保存。

## 首次创建

填写 API 设置后点击“创建 / 保存配置”。支持文件系统 API 的浏览器默认打开下载目录，使用固定文件名；请确认位置并授权。成功后页面会记住所选文件，配置修改后延迟约 700 毫秒写回，不重复创建配置文件。已存在同名文件时，可用“打开配置文件”选择它，避免覆盖已有内容。

浏览器不能静默创建、扫描或自动授权下载文件夹。下载目录是选择器的默认起点，最终位置由浏览器和你确定，不保证实际保存路径。

## 后续访问

页面在 IndexedDB 中仅记住文件句柄，不保存第二份密钥或配置。权限仍有效时自动读入；权限失效时点击“沿用上次配置”授权。浏览器清理站点数据或移动 / 删除文件后，重新点击“打开配置文件”选择即可。自动读取若发现你已开始编辑，则保留当前页面内容，避免覆盖。

配置修改后会自动保存到已读入或创建的文件。保存失败、权限不足时在 API 设置内显示状态。尚未创建文件时不自动下载；请点击“创建 / 保存配置”。“另存配置”明确更换文件。请勿同时在多个标签页编辑同一配置。

不支持 File System Access API 的浏览器只能导入 / 下载副本，无法保证不产生 `(1)` 等重复文件；需自行替换下载目录中的同名文件。推荐使用 Chrome / Edge 的 HTTPS 页面。

## 提示词与参考配置

默认提示词围绕补全中间步的讲解，以及命题 / 论文关键步骤的命名与正文回指。旧配置完整保留原有条目；点击“补充新版预制提示词”仅增加缺失的名称，不覆盖你的同名条目。

“参考配置”提供 DeepSeek、Kimi（国际）、通义千问（北京）官方示例。切换接口会清空密钥，随后填写对应服务商密钥。模型和地域权限以账户为准，浏览器直连仍需服务商支持 CORS。

结构兼容旧版：`{version:1,api:{baseURL,model,key},prompts:[{name,category,body}],preferences:{activePrompt,includeFile}}`，旧文件可省略 preferences。

配置含明文密钥，仅存放在你选择的本地文件中，请勿上传仓库或分享。调用 API 时密钥会发送到你填写的接口；网页运行环境可访问加载的配置。
