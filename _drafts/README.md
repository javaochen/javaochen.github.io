# _drafts

未定稿内容：可以公开（会进 git，`raw` 能读到），但**不渲染成网页**（Jekyll 跳过 `_` 开头的目录）。

## 和相邻位置的区别

| 位置 | 谁读得到 | 放什么 |
|---|---|---|
| `_private/` | 只有本机（`.gitignore` 忽略，独立 git，无远端） | 保密内容、私人草稿、状态记录 |
| `_drafts/` | 任何人（公开仓库 raw） | 还不想挂在网站上的稿子 |
| 根目录 / `about/` / `reports/` | 任何人（网站 + 仓库） | 已发布的页面 |

## 规则

- AI 代写内容默认集中在本目录的少数固定文件，持续更新原文件，不按对话或日期新增版本。具体约定见根目录 `AGENTS.md`。
- 固定草稿：`报告说明.md`、`公式定界符补丁.md`；个人状态草稿如需撰写，使用 `近期困扰.md`（尚未创建）。
- 更新时核对旧判断，标明 AI 整理、核对日期及待确认内容；不要把推测写成用户结论。
- 要"任何人都读不到" → `_private/`
- 只是"还不想挂在网站上" → 这里
- 定稿后移到 `about/` 或 `reports/`，补 front matter（`title` + `permalink`），并从首页加链接
